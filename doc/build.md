# Build

## Installation

The project is built using **Node.js v22.19.0**.  
Make sure you are using this version to avoid compatibility issues.

Below are the commands for building the project using **npm**, but you can use any other package manager you prefer.

```bash
# Install dependencies
npm install
```

### Build

```bash
# Build the project
npm run build
```

The production build will be generated in the `/dist` directory.
